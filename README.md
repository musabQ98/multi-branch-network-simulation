# Taibah University Multi-Branch Network Simulation

An enterprise-level multi-branch network architecture designed and simulated using Cisco Packet Tracer. This project establishes secure and reliable wide-area network (WAN) connectivity and data exchange between *Taibah University's Main Campus (Al-Madinah)* and its regional branches in *Yanbu* and *Badr*.

##  Network Topology & Architecture
- *Main Campus:* Taibah University (Al-Madinah Al-Munawwarah) serving as the core administrative and data hub.
- *Branch Offices:* 
  - Taibah University – Yanbu Branch
  - Taibah University – Badr Branch
- *Key Networking Features:*
  - *VLAN Segmentation:* Implemented Virtual Local Area Networks to separate academic, administrative, and guest traffic across all branches.
  - *Routing Protocols:* Configured dynamic routing to ensure seamless inter-branch communication and redundancy.
  - *DHCP & Services:* Deployed automated IP addressing and network services across all locations.

##  Tools & Technologies
- *Cisco Packet Tracer*
- *Networking Concepts:* WAN, VLANs, Routers, Switches, IP Addressing & Subnetting.

##  Project Files
- taibah-university-network.pkt: The complete Cisco Packet Tracer simulation file containing the entire topology, device configurations, and routing setups.
